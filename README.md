# Esttro

Интерпретатор языка программирования в рамках курса Системное программирование.
Ядро написано на Rust, а IDE реализована на Electron и React.

## Возможности

- Математика: целочисленная арифметика, числа с плавающей точкой (`float`, `double`), логика (`&&`, `||`, `!`).
- Управление потоком: ветвления `if` / `else`, циклы `for`, `while`, операторы `break` и `continue`.
- Функции: статическая типизация параметров и возвращаемых значений, взаимная рекурсия.
- Переменные: изменяемые `let` и строгие константы `const`.
- Встроенные функции: `print`, `assert`, приведение типов (`toInt`, `toFloat`, `toDouble`, `toString`, `toBoolean`).
- Графический интерфейс: редактор кода на Monaco Editor с выполнением по клавише F5.
- Подсветка синтаксиса: расширение для Visual Studio Code в папке `editors/vscode`.

## Запуск

### Графический интерфейс (IDE)

Требуется установленный Node.js (18 и новее).

Запуск через скрипт:

```cmd
run-notepad.bat
```

При первом запуске скрипт автоматически загрузит зависимости, соберет интерфейс и откроет окно редактора.
Если требуется использовать другой бинарник, путь передается аргументом:

```cmd
run-notepad.bat "...\esttro.exe"
```

### Консольный интерпретатор

Для сборки нужен Rust:

```cmd
cargo run -- examples\main.est
```

Сборка автономного бинарника:

```cmd
cargo build --release
```

## Структура проекта

- `bin/esttro.exe`: скомпилированный автономный бинарник под win-x64.
- `src/`: исходный код ядра на Rust (лексер, парсер, статический чекер, рантайм).
- `ide/`: исходный код редактора (Electron, React, Monaco Editor).
- `examples/`: `.est` файлы языка с примерами.
- `editors/vscode/`: расширение для VS Code с подсветкой синтаксиса.
- `run-notepad.bat`: скрипт запуска IDE.
