# MiniLang (Esttro)

Интерпретатор языка программирования на Rust в рамках зачётного задания по курсу «Системное программирование».

## Точный пошаговый пример: от написания кода до запуска

### Шаг 1. Создание файла с кодом

Создайте в папке проекта файл с расширением `.est` (например, `test_program.est`) в обычном Блокноте, VS Code или Notepad++:

```text
let a = 10;
let b = 25;
let result = a * 2 + b;

print("Результат вычислений: {result}");

if result > 40 {
    print("Условие выполнено: результат больше 40");
} else {
    print("Условие не выполнено");
}

let counter = 1;
while counter <= 3 {
    print("Итерация цикла: {counter}");
    counter = counter + 1;
}

print("Работа программы успешно завершена!");
```

> **Важно:** Сохраняйте файл в кодировке **UTF-8** (стандартное сохранение в Блокноте и VS Code).

---

### Шаг 2. Запуск программы через консоль

Откройте командную строку (cmd) или PowerShell в папке проекта и выполните команду:

```cmd
.\bin\esttro.exe test_program.est
```

*(Если запускаете из PowerShell, можно использовать ту же команду `.\bin\esttro.exe test_program.est`)*

---

### Шаг 3. Точный вывод в консоли

После нажатия Enter в консоли появится результат:

```text
Результат вычислений: 45
Условие выполнено: результат больше 40
Итерация цикла: 1
Итерация цикла: 2
Итерация цикла: 3
Работа программы успешно завершена!
```

## Готовые демонстрационные примеры

В папке `examples/` уже подготовлены файлы, демонстрирующие каждый пункт зачётного задания:

### 1. Комплексный запуск всех возможностей сразу
```cmd
.\bin\esttro.exe examples\06_comprehensive_demo.est
```
Выведет проверку математики со скобками, веток `if`/`else`, сравнений и работы цикла `while`.

### 2. Математика, переменные и приоритет операций
```cmd
.\bin\esttro.exe examples\01_math_and_variables.est
```

### 3. Ветвления if/else и 6 операций сравнения (==, !=, <, <=, >, >=)
```cmd
.\bin\esttro.exe examples\02_if_else.est
```

### 4. Цикл while с изменением переменных и проверкой условия
```cmd
.\bin\esttro.exe examples\03_while_loop.est
```

### 5. Проверка сообщений об ошибках
Проверка строгой типизации условий (число вместо `boolean` запрещено):
```cmd
.\bin\esttro.exe examples\04_invalid_condition_error.est
```
Вывод:
```text
examples\04_invalid_condition_error.est:4:4: typecheck error: condition must be of type boolean, found 'int'
```

Проверка защиты от деления на ноль:
```cmd
.\bin\esttro.exe examples\05_division_by_zero.est
```
Вывод:
```text
examples\05_division_by_zero.est:4:9: runtime error: division by zero
```

## Запуск через исходный код Cargo (для разработчиков)

Если на компьютере установлен компилятор Rust, исходный код можно запустить напрямую:

```cmd
cargo run -- examples\06_comprehensive_demo.est
```

## Возможности языка по техническому заданию

- **Базовая часть:**
  - Лексический анализ (Lexer) и синтаксический разбор (Parser) с построением AST.
  - Вычисление выражений (Evaluator / Interpreter) с представлением значений через `enum Value`.
  - Переменные: объявление через `let` и изменение значений.
  - Математические операции: сложение `+`, вычитание `-`, умножение `*`, деление `/`, остаток от деления `%`, унарный минус `-` и скобки.
  - Команда вывода `print` с поддержкой форматирования строк (`{переменная}`).
  - Обработка синтаксических ошибок и ошибок времени выполнения с указанием строки и колонки.
- **Обязательное задание:**
  - Операции сравнения: `==`, `!=`, `<`, `<=`, `>`, `>=` для чисел.
  - Логические значения: `true` и `false` с типом `boolean`.
  - Условные конструкции: `if <условие> { ... } else { ... }` (блок `else` опционален).
  - Строгая проверка условий (запрет чисел/строк вместо `boolean`).
- **Дополнительное задание:**
  - Цикл `while <условие> { ... }`.
  - Проверка условия перед каждой итерацией.
  - Изменение переменных внутри тела цикла.
  - Защита от бесконечного цикла (`MAX_LOOP_ITERATIONS = 1_000_000`).
